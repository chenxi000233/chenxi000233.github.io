# Xi Chen Academic Homepage

Static academic homepage for Xi Chen, Ph.D. student at the School of Computer Science, Wuhan University.

## Preview

Open `index.html` directly in a browser. No build command or web server is required.

## Structure

- `index.html`: homepage content
- `assets/styles.css`: responsive page styles
- `assets/site.js`: footer year script
- `assets/portrait.jpg`: profile photo
- `assets/figures/`: publication figures, research previews, and project visuals
- Original paper files are kept in the existing local paper directory.
